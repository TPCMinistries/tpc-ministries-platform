# Milestone v1.1 — "Best Ministry Site Ever" Plan (DRAFT)

> Drafted 2026-05-19 at the close of v1.0. **Not yet committed as the active milestone** — pending Lorenzo's review of the audit report at `/tmp/tpc-audit-report.md` and his green light on scope.

## Vision

Make tpcmin.org the **most engaging, trustworthy, conversion-ready ministry site on the internet** — for a Gen-Z–and–digital-age audience that's used to TikTok, Spotify, and Linear. Three layers:

1. **Foundation** — every promise the site makes actually works (assessments submit, signup emails fire, donations process, AI handoff lands cleanly)
2. **Engagement** — visitors stay >2 minutes, convert in measurable ways, come back daily
3. **Story** — every page deepens trust and the prophet's voice

## Themes for v1.1

### Theme A — Foundation Hardening (close the audit gaps)
Anything from `/tmp/tpc-audit-report.md` marked ⚠ or ✗ becomes scope. Likely targets:
- Assessments: end-to-end working (load → submit → save → result → email)
- Signup: welcome email + onboarding sequence + member row creation verified
- Giving: Stripe webhook verified, thank-you email, recurring donor flow
- Prayer requests: confirmation email, admin notification, follow-up touch
- Contact form: actually delivers to inbox

### Theme B — Performance + Mobile Experience
- Hero video → AVIF + WebM (3-5× smaller)
- Defer AI widget mount until idle (reduce TTI by ~500ms)
- `loading="eager"` only on first photo per gallery
- Image responsive sizes audit
- PWA install prompt polish
- Target: Mobile Lighthouse Perf ≥ 90, Accessibility 100, BP 100, SEO 100

### Theme C — Engagement Loops
- **Daily devotional email** — automated, opt-in at signup, pulls from Streams of Grace or new TPC source
- **Live alert** — when Lorenzo goes live (YouTube webhook or DB flag), the site shows a sitewide "WE'RE LIVE" interrupter; viewers can join directly
- **Push notifications** — VAPID is configured; wire prayer answered notifications, new teaching alerts, prophetic words
- **Member streak** — Duolingo-style "X days in the Word" with the daily devotional
- **Prayer wall** — public anonymized prayer requests with "I'm praying for this" counter

### Theme D — AI Deepening
- **Personalized daily devotional** — AI-generated for the member based on their season + recent journal entries
- **Prophecy archive search** — search past prophetic words by theme or date; AI can recall and reference them in chat
- **Voice replies** — optional spoken prophet response using ElevenLabs (Lorenzo voice clone)
- **Conversation memory** — member chat remembers past sessions and references them

### Theme E — Conversion Path Tightening
- **Analytics dashboard** — `/admin/analytics` page that shows the funnel (visits → AI chats → signups → first gift)
- **A/B test infrastructure** — start with hero copy variants
- **Heatmap** — install Vercel Analytics or PostHog session replay (optional, cost decision)
- **Donor receipts** — auto-PDF receipt for tax-deductible gifts

### Theme F — Content Velocity
- **Phone-to-publish** — Lorenzo records a teaching on his phone, drops in a Supabase storage bucket, the system auto-transcribes (Whisper), auto-generates a thumbnail, and stages a draft `teachings` row
- **Podcast Eps 1 & 2** from Day 10 — edit, mix audio, publish at /podcast/kenya-debrief
- **Auto-share** — when a new teaching publishes, schedule social posts (Buffer/Hootsuite API, or Postiz)

### Theme G — Trust Signals
- **Photos of Lorenzo + team** throughout (not just Kenya — US-side too)
- **Testimonial pull-quotes** on every key page
- **Press / appearances** strip on `/about`
- **Real member counter** — "X believers from Y countries are walking with us this week"
- **Live giving feed** (anonymized): "Someone in TX just gave $50" — when authorized

### Theme H — Multi-Language (stretch)
- Spanish for US Latinx audience
- Swahili for Kenya reach
- French for African Francophone reach
- Next.js i18n with content stored in DB columns by locale

## Out of scope for v1.1
- Mobile native app (web-first via PWA is fine)
- Live video hosting (use YouTube + Vimeo)
- Insta360 player (separate effort)
- Bulk ARW conversion of all 2,800 photos (curated 50 is enough)
- Custom CMS (Supabase + admin pages is enough)

## Sequencing intuition

Once audit report lands, the right order will be:
1. **Foundation gaps** (the audit ⚠/✗ items) — non-negotiable, you can't optimize what's broken
2. **Performance** — Lighthouse 90+ before adding more weight
3. **Engagement loops + AI deepening** — what creates daily habit
4. **Conversion path + content velocity** — what scales the work
5. **Trust signals + multi-language** — the polish layer
